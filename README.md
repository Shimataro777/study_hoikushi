# 暗記ノート｜保育士試験

人物・用語・年号を、単元ごとに4択と年号並べ替えで学習するWebアプリです。
すべてのファイルを同じ場所（1階層）に置けば動きます。

## 公開のしかた（GitHub Pages）
1. このフォルダのファイルをすべて、リポジトリのいちばん上の階層にアップロードします。
2. Settings → Pages で、Source を「Deploy from a branch」、ブランチを `main`、フォルダを `/(root)` にして保存します。
3. 1〜2分後に `https://ユーザー名.github.io/リポジトリ名/` で開けます。

スマホのブラウザで「ホーム画面に追加」すると、アイコンから起動できます。

## ファイル
| ファイル | 内容 |
|---|---|
| index.html | アプリ本体 |
| kyoiku-genri.js | 教育原理のデータ |
| hoiku-genri.js | 保育原理のデータ |
| hoiku-shinri.js | 保育の心理学のデータ |
| seido-nengo.js | 教育制度年号のデータ |
| manifest.webmanifest | ホーム画面に追加したときの名前とアイコン |
| icon.svg ほか *.png | アプリのアイコン |

## 問題の追加・編集（アプリ内）
- **編集・メモ**：解答後や振り分け一覧、図鑑の「編集・メモ」から、問題文・答え・解説などの修正とメモの追加ができます。
- **まとめて追加**：「データ」タブ →「まとめて追加」で「AIへの指示をコピー」を押し、AIに貼り付けて問題を作らせます。AIの出力を貼り付ける（またはテキストファイルを読み込む）と、まとめて追加できます。
- **1件ずつ追加**：「データ」タブ →「1件ずつ追加」。
- **バックアップ**：編集・メモ・追加した問題・学習記録はブラウザに保存されます。「データ」タブ →「バックアップを書き出す」でファイルに保存し、「バックアップから復元」で取り込めます。

### テキストの形式
1件ごとに `---` だけの行で区切ります。「用語」と「要約」があれば図鑑に、「問題」があれば4択問題にもなります。「年」と「出来事」を書くと年号の出来事になります。

```
用語: ルソー
読み: るそー
分野: 西洋の人物
要約: 18世紀フランスの思想家。『エミール』で消極教育を説いた。
解説: 子どもを独自の存在と捉え、「子どもの発見者」と呼ばれる。
問題: 『エミール』で「消極教育」を説いた人物は？
覚え方: エミール→ルソー→消極教育
---
年: 1872
和暦: 明治5
時代: 明治
出来事: 「学制」の制定
解説: わが国初の近代的な学校制度。
---
```
ほかに「単元:」（追加先の単元名）、「除外:」（誤りの選択肢に出さない語を「、」区切り）、「メモ:」も使えます。

## データファイルを直接編集する場合
- 各単元の .js ファイルの冒頭に書き方があります。
- 単元を増やすときは、同じ形式の .js ファイルを置き、index.html の「学習データ」の部分に `<script src="ファイル名.js"></script>` を1行追加します。
- 単元のアイコンは `icon` に `cap`・`blocks`・`sprout`・`calendar`・`book` のいずれかを指定します。
