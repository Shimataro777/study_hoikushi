# 暗記ノート｜保育士試験

バージョン 1.1.0（2026-10-20）　※アプリの「データ」画面のいちばん下にも表示されます。

人物・用語・年号を、単元ごとに4択と年号並べ替えで学習するWebアプリです。
すべてのファイルを同じ場所（1階層）に置けば動きます。

## 公開のしかた（GitHub Pages）
1. このフォルダのファイルをすべて、リポジトリのいちばん上の階層にアップロードします。
2. Settings → Pages で、Source を「Deploy from a branch」、ブランチを `main`、フォルダを `/(root)` にして保存します。
3. 1〜2分後に `https://ユーザー名.github.io/リポジトリ名/` で開けます。

スマホのブラウザで「ホーム画面に追加」すると、アイコンから起動できます。

## データの考え方
- アプリは空の枠で、問題はすべて端末の中の置き場に入ります。
- はじめて開いたときに、付属の問題ファイル（kyoiku-genri.js など）が自動で取り込まれます。取り込んだあとは、自分で足した問題と区別なく、直したり消したりできます。
- 付属の問題ファイルを新しくしたときは、「データ」→「付属の問題ファイルから取り込む」で、まだ無いものだけを確認画面から選んで取り込めます。

## 学習の機能
- **施設の職員配置**（1.1.0〜）：「学習」画面の下の「表で覚える」から開きます。1施設＝1問で、乳児院（10人以上／10人未満）・児童養護施設・児童心理治療施設・児童自立支援施設・母子生活支援施設の6問。全15職種それぞれに ●必置／○条件によって配置／△条件によって配置しないことができる／－規定なし を選んで答え合わせします。答え合わせのあと、職種ごとの理由、施設のポイント、人数規模による違い（乳児院）、覚え方が出ます。「早見表」で全施設の一覧と覚えるコツも見られます。振り分け・効果音・自信なし・わからない・苦手を復習は、ほかの問題と同じように使えます。内容を直すときは shokuin-haichi.js を書き換えます（アプリ内の編集・振り分け一覧の対象外）。
- **出題の向き**：4択は「説明 → 答え」（説明を読んで人物・用語を選ぶ）と「答え → 説明」（人物・用語を見て正しい説明を選ぶ）の2通りがあり、出題の設定で選べます（まぜることもできます）。振り分けは向きごとに記録されます。
- **人物の国と時代**：人物には、活動した国・地域と生没年（はっきりしないものは時期）が付いています。解答後・図鑑・選択肢の解説に表示されます。
- **わからない**：4択・年号並べ替えで「わからない」を選ぶと、正解と解説を確認でき、「わからない」に振り分けられます。
- **出題する問題**：出題の設定で、未回答・わからない・不正解・自信なし・正解をチェックで自由に組み合わせられます。「すべて」「苦手」でまとめて切り替えもできます。
- **苦手を復習**：不正解・わからない・自信なしの問題をまとめて解けます。
- **中断**：問題の途中で × を押す（または戻る操作をする）と、確認なしでそこで終わります。解いた分の振り分けはそのまま保存され、残りの問題は出題されません。
- **効果音**：正解・不正解・連続正解・結果発表で音が鳴ります。問題中の右上のボタンか「データ」→「設定」でオン・オフできます。
- **ふりがな**：人名・書名・用語にふりがなが付きます。「データ」→「設定」でオン・オフできます。「ふりがなの辞書」には登録済みの読みがすべて並び、行を押すと修正・非表示、「追加」で新しい語を登録できます。
- **検索**：図鑑・振り分けの上のキーワード欄に打つと、その場で絞り込まれます（読みをひらがなで打っても探せます）。単元・分野・振り分けで絞りたいときだけ「絞り込み」を押し、プルダウンで選びます。かかっている条件はキーワード欄の下に表示され、×で外せます。

## 問題の追加・編集（アプリ内）
- **編集・メモ**：解答後や振り分け一覧、図鑑の「編集・メモ」から、問題文・答え・解説などの修正とメモの追加ができます。
- **まとめて追加**：「データ」タブ →「まとめて追加」で「AIへの指示をコピー」を押し、AIに貼り付けて問題を作らせます。AIの出力を貼り付ける（またはテキストファイルを読み込む）と、「取り込む内容の確認」画面が開きます。チェックで取り込むものを選び、項目を押せば取り込む前に中身を直せます。
- **1件ずつ追加**：「データ」タブ →「1件ずつ追加」。
- **バックアップ**：編集・メモ・追加した問題・学習記録はブラウザに保存されます。「データ」タブ →「バックアップを書き出す」でファイルに保存し、「バックアップから復元」で取り込めます。

### テキストの形式
1件ごとに `---` だけの行で区切ります。「用語」と「要約」があれば図鑑に、「問題」があれば4択問題にもなります。「年」と「出来事」を書くと年号の出来事になります。

```
用語: ルソー
読み: るそー
分野: 西洋の人物
要約: 18世紀フランスの思想家。『エミール』で消極教育を説いた。
解説: 子どもを独自の存在と捉え、「子どもの発見者」と呼ばれる。
問題: 『エミール』で「消極教育」を説いた人物は？
覚え方: エミール→ルソー→消極教育
---
年: 1872
和暦: 明治5
時代: 明治
出来事: 「学制」の制定
解説: わが国初の近代的な学校制度。
---
```
ほかに「単元:」（追加先の単元名）、「除外:」（誤りの選択肢に出さない語を「、」区切り）、「メモ:」も使えます。

## 操作の決まり
- 画面の左上の「‹ 戻る」を押すと、必ず一つ前の画面に戻ります。問題を解いている画面は × で終わります（解いた分の振り分けは保存されます）。
- 画面の行き来はアプリの中だけで管理しています（ブラウザの戻る履歴は使いません）。そのため、スワイプでは戻りません。
- ホーム画面に追加したWebアプリは、ほかのアプリへ切り替えたあとなどに iOS が裏で読み込み直すことがあります。そのときも、開いていた画面（解いている途中の問題も）から続けられます。
- 一覧から詳細へ進む画面は右から、問題を解く画面は下から入ります。
- 下のタブをもう一度押すと、1回めでいちばん上へ、2回めで最初の表示（検索なし）に戻ります。
- 削除・リセット・復元などは、必ず確認の小窓が出ます。編集中に ✕ で閉じようとしたときも確認が出ます。
- 振り分けの一覧では、問題をいくつでも同時に開いておけます。開いたり閉じたりしても画面は動きません。
- ダブルタップや文字入力で画面が拡大されないようにしています。

## データファイルを直接編集する場合
- 各単元の .js ファイルの冒頭に書き方があります。
- 単元を増やすときは、同じ形式の .js ファイルを置き、index.html の「学習データ」の部分に `<script src="ファイル名.js"></script>` を1行追加します。
- ふりがなを増やすときは、ruby.js に `"語": "よみ"` を追加するか、用語データの `kana` に読みを書きます。
- 単元のアイコンは `icon` に `cap`・`blocks`・`sprout`・`calendar`・`book` のいずれかを指定します。
- 単元の追加・並べ替え（つまみを押さえて上下に動かす）・名前の変更・削除は、アプリの「データ」→「単元」でも行えます。
