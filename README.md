# 暗記ノート｜保育士試験

バージョン 1.22.4（2026-10-24）　※アプリの「データ」画面のいちばん下にも表示されます。

人物・用語・年号・法令を、単元ごとに「覚える（カード）」と「問題を解く（4択・○×・一覧○×・年号並べ替え）」で学習するWebアプリです。
すべてのファイルを同じ場所（1階層）に置けば動きます。

> **内容（問題・単元・図鑑・表・年表）は、これからはすべて Claude が作ります。** アプリの中で問題を足す機能はありません。
> 足す・直すときは、データファイルを書き換えます。**書き方は [CONTENT-GUIDE.md](CONTENT-GUIDE.md)**、書いたあとの点検は `node tools/check.mjs` です。

## 公開のしかた（GitHub Pages）
1. このフォルダのファイルをすべて、リポジトリのいちばん上の階層にアップロードします（`tools/` と `*.md` は置かなくても動きます）。
2. Settings → Pages で、Source を「Deploy from a branch」、ブランチを `main`、フォルダを `/(root)` にして保存します。
3. 1〜2分後に `https://ユーザー名.github.io/リポジトリ名/` で開けます。

スマホのブラウザで「ホーム画面に追加」すると、アイコンから起動できます。

## 画面
- **学習**：単元の一覧 →（単元ページ）「覚える」「問題を解く」の切り替え。どちらも**大分類**（例：教育原理なら「教育法規」「特別支援・学校評価」「教育制度・用語」「西洋の人物」…）の行だけを並べます。押すと、覚える＝カードが始まり、問題を解く＝出題の設定（すべて／苦手／未回答、10問／20問／すべて）が開きます。形式・向き・分野の細かい絞り込みは「くわしい設定」にたたんであります。
- **表**：比較の表・早見表。検索と「単元・分野」の絞り込みで探します。表は**左端の項目名を固定**し、スマートフォンでは「見る列」で列を絞れます。左の□で2〜4行を選ぶと、**行どうしを縦に並べて比べる**表示になります。
- **図鑑**：「用語・人物」と「年表」の2つのタブ。検索と絞り込みで探します。ほかの画面（単元ページ・解答のあと）から開くときは、紙（ダイアログ）として開き、✕ で元の画面に戻れます。表も同じです。
- **データ**：メモ、ふりがなの辞書、設定、バックアップ、データの確認事項、アプリの更新。

## 問題の種類
- **4択**：用語ごとに自動で作られます（説明→答え、答え→説明の両方向。誤りの選択肢は同じ単元・同じ分野の用語）。
- **○×（試験の形）**：1セット＝5つの記述に○か×。答えると比較の表が出ます。
- **一覧○×**：「すべての項目」を1問にまとめた○×です。ワクチンの接種回数、感染症ごとの感染経路、登園・出席停止の目安、条文の見出し、「どの法令に定められているか」など、表のように覚えるものに使います。**出題のたびに、どれを正しい記述にするか（○と×）を組み直す**ので、答えの位置では覚えられません。
- **年号**：出来事→年、並べ替え。
- **職員配置**：施設ごとの配置、職種から施設を選ぶ（まとめて1セット）。

## データの考え方
- 用語と年号は、はじめて開いたときに端末の「置き場」（ブラウザの保存領域）に取り込まれます。**付属のファイルに足したものは、次に開いたときに自動で入ります**（`syncBundle`）。用語・年号に `rev: 1` を書くと、置き場の内容がファイルのものに置きかわります（直すたびに数字を上げる）。やめるときは単元に `removeTerms` / `removeEvents` を書きます。
- ○×・一覧○×・並べ替え・表・早見表・ことばの補足・解説は、置き場に入れず、いつもファイルから直接読みます。直せばすぐ変わります。
- 学習記録（正解・苦手・覚えた）は問題の id ごとに保存されます。**既存の id は変えないでください**（変えると、その問題の記録が消えます）。
- バックアップ（「データ」→「バックアップ」）に、メモ・語呂合わせ・学習記録が入ります。

## 操作の決まり
- 画面の左上の「‹ 戻る」を押すと、必ず一つ前の画面に戻ります。問題を解いている画面は × で終わります。
- 画面の行き来はアプリの中だけで管理しています（ブラウザの戻る履歴は使いません）。
- ホーム画面に追加したWebアプリは、iOS が裏で読み込み直すことがあります。解いている途中の問題は復元されます。
- 下のタブは「学習」「表」「図鑑」「データ」の4つです。もう一度押すと、1回めでいちばん上へ、2回めで最初の表示に戻ります。
- 削除・リセット・復元などは、必ず確認の小窓が出ます。
- ダブルタップや文字入力で画面が拡大されないようにしています。

## 開発メモ（申し送り）
アプリを直す人・AIに作業を頼むときは、この節もいっしょに渡してください。

### ふりがなの表記崩れを起こさないための決まり
過去に2回、ふりがなの付いた語のまわりで表示が崩れました（早見表の番号付きの欄で文が縦にばらばらになる、回答画面で「水痘 ワクチン」のように語が離れる・下にずれる、「百日咳」の前後にすき間が空く）。原因と決まりは次のとおりです。

1. **ふりがなは必ず `furi(語, 読み)` で作る。HTML の `<ruby>` `<rt>` は使わない。**
   ブラウザ標準の ruby は、読みが語より長いと語の前後にすき間を空ける。`furi()` は読みを語の上に重ねるだけで、語の幅を変えない（見た目は CSS の `.fr` `.frt`）。
2. **ふりがなが入る文は `rb(文)` か `rbL(文)` で作り、結果をそのまま使う。**
   どちらも文全体を `<span class="rtx">` で包むので、flex や grid の箱（選択肢の見出し、行の見出し、表のセル、番号付きの欄など）に入れても、ふりがなの語とまわりの文字が別々の部品として並ばない。文を自分で分割して、ふりがなの部分だけを flex/grid の箱に直接入れないこと。
3. **番号や印を付けた欄は、文を `<span>` で包む。** 箱を `display:grid` にして左に番号を置くときは、文の側を1つの `<span>` にまとめる（`.stips` の作りを参照）。
4. **直したら確かめる。** ふりがなの付く語（例：水痘、百日咳、愛着、社会的参照）が入る画面を、スマホの幅（390px）と iPad の幅で開き、すき間・段ずれ・縦並びがないかを見る。


### そのほか
- 内容を足す・直す手順は [CONTENT-GUIDE.md](CONTENT-GUIDE.md)。**書いたら `node tools/check.mjs`**（書き方の誤り・id の重複・存在しない表の指定を見つけます）。
- 更新したら `index.html` の `APP_VERSION`、`<script src="...js?v=…">` の版の印、`sw.js` の `VERSION` の3つを同じ数字にそろえる（端末に古いファイルが残らないようにするため）。.js を足したら、`index.html` の読み込みと `sw.js` の `JS` の一覧にも足す。`check.mjs` が、そろっているかも見ます。
- 画面の部品：`render*` が画面を作り、`onAction` の `data-act` で操作を受けます。画面の移動は `go` / `uiBack`、紙（ダイアログ）は `openModal`。
- 大事なことばの色は `hl(文, { unit, self, link })`。図鑑の語句と年号・『書名』に色をつける。ボタンの中などで入れ子になるときは、リンクにしない。
- 覚えるカードの key は、語句＝`t:語句のkey`、年号の流れ＝`g:単元|時代#番号`、○×＝`d:セットid`、職員配置＝`s:施設id`。
- 図鑑のまとめは `buildMasters()` で作る（`term` から空白・中黒・＝を除いた名前、または `master` が同じものを束ねる）。
- 表は `tblHTML` が作る（左端固定・列の絞り込み・行の比較）。比較の表は、データファイルの `tables`（単元のもの）か、`DEVCHECK(S)` の `tables`（○×の解答のあとに出す表）に書く。
- 一覧○×は `relist()`（index.html）が、出題のたびに正誤を組み直して `items` を作る。解答の画面・記録は通常の○×と同じ。
- CSS で `.○○ span{…}` のように「中の span すべて」に枠・余白・文字の大きさを付けない。ふりがなの部品（`.rtx` `.fr` など）にも効いてしまう。
- 文の中の改行は `\n` と書く。JavaScript の文字列の途中で本当に改行すると、アプリ全体が動かなくなる。
- データファイルを足したら、`node --check ファイル名` と `node tools/check.mjs` で確かめる。
- 画面の確認は、スマートフォンの幅（390px）で行う（Playwright など）。
