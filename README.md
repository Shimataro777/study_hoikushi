# 暗記ノート｜保育士試験

バージョン 1.26.0（2026-10-25）　※アプリの「データ」画面のいちばん下にも表示されます。

人物・用語・年号を、単元ごとに「覚える（カード）」と「問題を解く（4択・○×・年号並べ替え）」で学習するWebアプリです。
すべてのファイルを同じ場所（1階層）に置けば動きます。

## 公開のしかた（GitHub Pages）
1. このフォルダのファイルをすべて、リポジトリのいちばん上の階層にアップロードします。
2. Settings → Pages で、Source を「Deploy from a branch」、ブランチを `main`、フォルダを `/(root)` にして保存します。
3. 1〜2分後に `https://ユーザー名.github.io/リポジトリ名/` で開けます。

スマホのブラウザで「ホーム画面に追加」すると、アイコンから起動できます。

## データの考え方
- アプリは空の枠で、問題はすべて端末の中の置き場に入ります。
- はじめて開いたときに、付属の問題ファイル（kyoiku-genri.js など）が自動で取り込まれます。取り込んだあとは、自分で足した問題と区別なく、直したり消したりできます。
- 付属の問題ファイルを新しくしたときは、「データ」→「付属の問題ファイルから取り込む」で、まだ無いものだけを確認画面から選んで取り込めます。

## 学習の機能

- **学習の記録の欄をなくす**（1.25.2）：ホームの「今日・この7日」の問題数と曜日ごとの棒の欄を削除し、日ごとの解いた数も記録しないようにしました（前に記録した分も消します）。単元ごとの進み具合はそのままです。
- **法令の問題を「どの法令か」にまとめる**（1.25.0）：教育原理の法令の4択を、条文の文面や定義から「定めている法令」を答える形にしました。日本国憲法・教育基本法・学校教育法・児童福祉法・母子保健法・児童虐待防止法・子ども・子育て支援法・児童手当法・こども基本法・少年法・労働基準法・民法・認定こども園法を、同じ分野「法令：どの法令か」でまとめて出題します。子どもの定義と学校の範囲は、記述の頭に法律の名前を置いた○×で、法律ごとにくらべられるようにしました。条文の意味（だれの権利・義務か、無償の範囲など）を問う○×は「条文の読み取り」に残し、それ以外の前の語句（教育を受ける権利・乳児・幼稚園など）と○×は廃止しました。
- **第4期教育振興基本計画**（1.24.0）：教育原理に「教育制度：用語」として、教育振興基本計画・第4期教育振興基本計画・ウェルビーイング・持続可能な社会の創り手を足しました。「日本社会に根差した○○の向上」の答えはウェルビーイングです。答えが計画の名前になっていた穴うめ問題は、正しい答えの問題へ移します。

- **子ども・学校の定義と比較表**（1.23.0〜）：教育原理に「法令上の定義」の分野を加えました（語句31・○×4セット・比較表4つ）。比較表は「乳児・幼児・少年など（児童福祉法・母子保健法・学校教育法）」「『子ども』の範囲（法律ごと）」「学校と児童福祉施設の区分」「幼稚園・保育所・幼保連携型認定こども園」です。答えのあとの解説と「表」のタブに出ます。社会的養護・子どもの保健の関連する○×にも、同じ表を付けました。

### テキストの形式
1件ごとに `---` だけの行で区切ります。「用語」と「要約」があれば図鑑に、「問題」があれば4択問題にもなります。「年」と「出来事」を書くと年号の出来事になります。

```
用語: ルソー
読み: るそー
分野: 西洋の人物
要約: 18世紀フランスの思想家。『エミール』で消極教育を説いた。
解説: 子どもを独自の存在と捉え、「子どもの発見者」と呼ばれる。
問題: 『エミール』で「消極教育」を説いた人物は？
覚え方: エミール→ルソー→消極教育
---
年: 1872
和暦: 明治5
時代: 明治
出来事: 「学制」の制定
解説: わが国初の近代的な学校制度。
---
```
ほかに「単元:」（追加先の単元名）、「除外:」（誤りの選択肢に出さない語を「、」区切り）、「メモ:」も使えます。

## 操作の決まり
- 画面の左上の「‹ 戻る」を押すと、必ず一つ前の画面に戻ります。問題を解いている画面は × で終わります（解いた分の振り分けは保存されます）。
- 画面の行き来はアプリの中だけで管理しています（ブラウザの戻る履歴は使いません）。そのため、スワイプでは戻りません。
- ホーム画面に追加したWebアプリは、ほかのアプリへ切り替えたあとなどに iOS が裏で読み込み直すことがあります。そのときも、開いていた画面（解いている途中の問題も）から続けられます。
- 一覧から詳細へ進む画面は右から、問題を解く画面は下から入ります。
- 下のタブをもう一度押すと、1回めでいちばん上へ、2回めで最初の表示（検索なし）に戻ります。
- 削除・リセット・復元などは、必ず確認の小窓が出ます。編集中に ✕ で閉じようとしたときも確認が出ます。
- 下のタブは「学習」「表」「図鑑」「データ」の4つです（1.21.0で「振り分け」のタブをなくし、「表」を置きました）。
- ダブルタップや文字入力で画面が拡大されないようにしています。

### ふりがなの表記崩れを起こさないための決まり
過去に2回、ふりがなの付いた語のまわりで表示が崩れました（早見表の番号付きの欄で文が縦にばらばらになる、回答画面で「水痘 ワクチン」のように語が離れる・下にずれる、「百日咳」の前後にすき間が空く）。原因と決まりは次のとおりです。

1. **ふりがなは必ず `furi(語, 読み)` で作る。HTML の `<ruby>` `<rt>` は使わない。**
   ブラウザ標準の ruby は、読みが語より長いと語の前後にすき間を空ける。`furi()` は読みを語の上に重ねるだけで、語の幅を変えない（見た目は CSS の `.fr` `.frt`）。
2. **ふりがなが入る文は `rb(文)` か `rbL(文)` で作り、結果をそのまま使う。**
   どちらも文全体を `<span class="rtx">` で包むので、flex や grid の箱（選択肢の見出し、行の見出し、表のセル、番号付きの欄など）に入れても、ふりがなの語とまわりの文字が別々の部品として並ばない。文を自分で分割して、ふりがなの部分だけを flex/grid の箱に直接入れないこと。
3. **番号や印を付けた欄は、文を `<span>` で包む。** 箱を `display:grid` にして左に番号を置くときは、文の側を1つの `<span>` にまとめる（`.stips` の作りを参照）。
4. **直したら確かめる。** ふりがなの付く語（例：水痘、百日咳、愛着、社会的参照）が入る画面を、スマホの幅（390px）と iPad の幅で開き、すき間・段ずれ・縦並びがないかを見る。

- 覚えるカードの key は、語句＝`t:語句のkey`、年号の流れ＝`g:単元|時代#番号`、○×＝`d:セットid`、職員配置＝`s:施設id`。振り分けは `P.m[key] = { b: 'ok' | 'unsure', t }`、語呂合わせは `hoikushi-anki-goro-v1` に `{ [key]: { text, s: [線…], t } }`（線は `{ c: 色, w: 太さ, e: 消しゴムなら1, p: [x, y, …] }`、座標は 800×560 の紙の上の整数）。
- 図鑑のまとめは `buildMasters()` で作る（`term` から空白・中黒・＝を除いた名前、または `master` が同じものを束ねる）。`openTerm(key)` は、その語句を含むまとめを開く。
- 更新したら `sw.js` の `VERSION` も `APP_VERSION` と同じにする（古い保存を消して新しいファイルを保存し直すため）。.js を足したら `sw.js` の `JS` にも書き足す。
- ○×チェックは単元ごとに持てる（子どもの保健＝kodomo-hattatsu.js の `window.DEVCHECK`、ほかの単元＝`window.DEVCHECKS` に push）。ことばの補足も同じく `window.GLOSS` と `window.GLOSSES`。○×のセットの id・表の名前は、単元をまたいで重ならないようにする（社会的養護は `y-` で始める）。並べ替えの問題文は `lead` で変えられる（例：「古い年のものから順に」）。
- 比較の表は、子どもの保健は kodomo-hattatsu.js の `tables`、ほかの単元はその単元のデータファイルの `tables` に書く（`{ title, genre, cols, rows, note }`）。語句に `tbl: "表の名前"` を書くと、解答のあと・図鑑に表が出る。単元ページに分野だけを解く行を出すときは、データファイルに `focus: [{ genre, desc }]` を書く。
- 付属ファイルに語句を足したときは、`index.html` の `ADDED_UNITS` に「単元id#番号」を1つ足す（すでに使っている端末に一度だけ追加される）。
- CSS で `.○○ span{…}` のように「中の span すべて」に枠・余白・文字の大きさを付けない。ふりがなの部品（`.rtx` `.fr` `.frt`）も span なので、読みが語と同じ大きさになって重なる（1.15.1まで「答え」の欄で起きた）。ラベルだけに付けたいときは `> span:first-child` やクラス名で指定する。
- データファイル（kodomo-*.js など）を足したら、`node --check ファイル名` で文法を確かめ、配列にからの要素（`,,` や `*/,`）ができていないか見る。からの要素があるとアプリが起動しなくなる（1.15.0の作業中に起きた）。
- 文の中の改行は `\n` と書く。JavaScript の文字列の途中で本当に改行すると、アプリ全体が動かなくなる（1.7.0で起きた）。
- 更新したら `index.html` の `APP_VERSION` と、`<script src="...js?v=…">` の版の印を両方上げる（端末に古いファイルが残らないようにするため）。
